# Тренажёр формул ЕГЭ

Интерактивный тренажёр для запоминания математических формул и отработки заданий.

## Запуск

Откройте `index.html` через веб-сервер. Для публикации проект можно развернуть как статический сайт на Timeweb Cloud.

Текущая версия работает без регистрации: прогресс сохраняется локально в браузере пользователя.

## Документы и регистрация

Внизу главной находятся ссылки на `terms.html` (пользовательское соглашение)
и `register.html` (страницу будущей регистрации). `personal-data.html`
описывает подготовку документов об обработке персональных данных;
это информационная страница, а не действующее согласие или политика.
Страницы используют локальный `legal.css`, работают без JavaScript и не собирают данные.
Регистрация пока отключена, её элементы согласия не принимают и не сохраняют отметки.
Для публикации нужно загрузить все четыре новых файла вместе с `index.html`.

2 октября 2026 подключение сервера и запуск регистрации отложены для проверки
платформы в режиме без аккаунта. На главной размещено уведомление о будущей
регистрации и хранении прогресса в текущем браузере. Подготовленный сервер
сохранён отдельно в черновике PR #9; он не включён в опубликованную версию.
План на будущее: `docs/registration-plan.md`.

## Возможности

В банке 2280 заданий: формулы, общая практика и отдельная подготовка к первой и второй частям по проекту профильного ЕГЭ-2027. Для первой части есть точный ввод чисел, дробей и периодов; для второй — черновики, образцы и учебные критерии самопроверки. Это тематический тренажёр, а не полный пробный экзамен.

## Проверки

Из корня проекта, без дополнительных пакетов:

```sh
node tests/check_numeric.cjs
python tests/check_exam_bank.py
node tests/check_statistics.cjs
```

Подробности состава банка и публикации — в `README_TIMEWEB.txt`.

## Важно

Секретные ключи, пароли и платёжные токены нельзя добавлять в этот репозиторий. При появлении аккаунтов и оплаты они должны храниться в переменных окружения серверного приложения.
